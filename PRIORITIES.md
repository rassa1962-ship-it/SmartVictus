# Анализ и приоритеты SmartVictus

## 📊 Текущее состояние проекта

### ✅ Реализовано (готовые функции)
- Инвентарь продуктов (холодильник, кладовка, морозилка)
- Сроки годности с уведомлениями
- Список покупок
- Сканер штрих-кодов
- OCR сканирование чеков (ocr.space)
- AI автосортировка по категориям
- Интеграция с Open Food Facts API
- Тёмная тема
- Экспорт/импорт данных
- История действий

## 🎯 Приоритеты развития

### ПРИОРИТЕТ 1: Firebase синхронизация (Критично)
**Статус:** Инструкция создана, нужна реализация

Почему важно:
- Данные хранятся локально (AsyncStorage)
- Нет синхронизации между устройствами
- Нет резервного копирования
- Нет family sharing

**Задачи:**
- [ ] Установить firebase, @react-native-firebase/auth, @react-native-firebase/firestore
- [ ] Создать src/services/firebase.ts
- [ ] Создать src/services/auth.ts (email/password)
- [ ] Создать src/services/firestore.ts (households, products)
- [ ] Создать src/services/migration.ts (миграция с AsyncStorage)
- [ ] Обновить App.tsx для Auth
- [ ] Добавить экран входа/регистрации

**Сложность:** Средняя
**Время:** 2-3 часа

---

### ПРИОРИТЕТ 2: Уные прогнозмы (Высокий)
**Статус:** Не начато

Почему важно:
- Уникальная функция для рынка
- Помогает пользователю планировать
- Конкурентное преимущество

**Задачи:**
- [ ] Динамическая корректировка срока годности (по истории)
- [ ] Прогноз "скоро испортится" с учётом привычек
- [ ] Прогноз потребления ("закончится через N дней")
- [ ] Контекстные советы и рекомендации

**Сложность:** Высокая (нужна ML/алгоритмы)
**Время:** 1-2 недели

---

### ПРИОРИТЕТ 3: Рецепты (Средний)
**Статус:** Документация есть (RECIPES.md)

Почему важно:

- "Что приготовить из того, что скоро испортится" - мощная фича
- Повышает вовлечённость

**Задачи:**
- [ ] Создать экран RecipesScreen
- [ ] Интегрировать TheMealDB API
- [ ] Добавить кнопку "Рецепты из того, что скоро испортится"
- [ ] Показывать рецепты по ингредиентам

**Сложность:** Низкая-средняя
**Время:** 3-5 часов

---

## 🛠 Технические долги

1. **TypeScript типы** - проект частично на TS, но нужна строгая типизация
2. **Тесты** - нет юнит-тестов
3. **CI/CD** - нет автоматической сборки
4. **Документация кода** - можно улучшить JSDoc
