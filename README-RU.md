# SmartVictus 🏠

Умное приложение для управления продуктами и сроками годности. Создано с React Native (Expo).

## 📱 Описание

SmartVictus помогает отслеживать сроки годности продуктов в вашем холодильнике, кладовке и морозилке. Никогда не забывайте о скоропортящихся продуктах!

**Доступно на:** iOS, Android

## ✨ Функции

### Текущие возможности
- 📦 **Инвентарь** - управление продуктами в разных местах хранения
- ⏰ **Сроки годности** - отслеживание с визуальными индикаторами
- 🛒 **Список покупок** - планирование покупок
- 📊 **Главная страница** - обзор продуктов с истекающим сроком
- 🔍 **Поиск** - поиск продуктов по названию
- 📂 **Категории** - группировка (молочные, мясо, овощи и т.д.)
- ✏️ **Редактирование** - изменение данных о продукте
- 📜 **История** - логирование действий
- 📷 **Сканер штрих-кодов** - сканирование и автозаполнение
- 🌙 **Тёмная тема** - поддержка светлой и тёмной темы
- 🔔 **Push-уведомления** - напоминания о сроке годности
- ⚙️ **Настройки** - настройка уведомлений и темы

### Умные функции
- 🧠 **AI автосортировка** - автоматическая категоризация
- 📷 **OCR сканирование чеков** - сканирование чеков (ocr.space, бесплатно)
- 🔎 **Open Food Facts API** - автоматический поиск данных о продуктах
- 📤 **Экспорт/импорт** - резервное копирование

## 🚀 Запуск

### Требования
- Node.js 18+
- npm или yarn
- Expo Go (для тестирования на телефоне)

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/rassa1962-ship-it/SmartVictus.git
cd SmartVictus

# Установить зависимости
npm install

# Запустить сервер разработки
npx expo start

# Запустить на Android
npx expo start --android

# Запустить на iOS
npx expo start --ios
```
